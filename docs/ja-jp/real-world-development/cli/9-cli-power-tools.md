多くの CLI ツールと同様に、GitHub Copilot CLI には対話に使えるスラッシュコマンドが多数用意されています。高度な機能、内部情報、追加の設定オプションを利用できます。これまでに `/diff`、`/mcp`、`/skills`、`/agent`、`/pr` などのコマンドを使いました。ここでは、ほかの便利なコマンドを確認します。

このレッスンでは、次のことを行います。

- `/context` と `/compact` を使い、Copilot が会話のコンテキストを管理する方法を確認します。
- `/model` を使い、使用できるモデルを確認します。
- `/share` でセッションをエクスポートまたは共有する方法を学びます。
- 並行作業、worktree、クラウドエージェントへの委任に使う任意のコマンドを確認します。

## シナリオ

CLI の主要なワークフローが完了しました。次は、コンテキストの管理、モデルの切り替え、セッションの共有、任意の [Copilot クラウドエージェント][about-cloud-agent]への委任など、追加機能を確認します。

## Copilot CLI のコンテキストを確認する

大規模または複雑なタスクに取り組むと、モデルのコンテキストウィンドウの上限に近づくことがあります。Copilot CLI は必要に応じて会話を自動的に圧縮しますが、スラッシュコマンドを使って確認したり、自分で圧縮したりすることもできます。

1. Codespace に戻り、Copilot CLI が起動していない場合は、リポジトリのルートから起動します。
2. 次のコマンドを入力します。

   ```plaintext
   /context
   ```

3. モデル、現在のトークン使用量、システム指示、ツール、メッセージ、空き領域でコンテキストがどのように構成されているかを確認します。
4. 会話を圧縮します。

   ```plaintext
   /compact
   ```

5. もう一度 `/context` を入力して結果を比較します。会話が短い場合は、大きな違いが見られないことがあります。

> [!NOTE]
> コンテキストウィンドウが埋まると、Copilot CLI は自動的にコンテキストを圧縮します。自分のタイミングで圧縮する場合は `/compact` を使います。関係のない別タスクを始める場合は、`/clear` または `/new` で新しい会話を開始します。

## モデルを選ぶ

モデルによって得意分野が異なり、開発者ごとに好みも異なります。Copilot CLI では使用可能なモデルを一覧表示し、利用するモデルを選択できます。

1. 次のコマンドを入力します。

   ```plaintext
   /model
   ```

2. 利用可能なモデルと使用状況に関する情報を確認します。
3. 現在のモデルを使うか、別のモデルを選ぶか、<kbd>Esc</kbd> を押して一覧を閉じます。

## セッションを共有する

チームで協力して学びを共有すると、AI ツールの活用方法を改善できます。`/share` コマンドを使うと、セッションを Markdown または HTML ファイルにエクスポートしたり、共有リンクを作成したり、GitHub gist を公開したりできます。

1. `/help` を入力し、インストール済みのバージョンにおける `/share` のオプションを確認します。
2. セッションを共有する場合は、目的に合った出力先を選びます。たとえば `/share file` では、ローカルに Markdown ファイルをエクスポートできます。
3. エクスポートした内容を送信または公開する前に確認します。セッションのエクスポートには、プロンプト、応答、プロジェクトの詳細が含まれることがあります。

リンクや gist の公開は任意です。チームが共有するつもりのないリポジトリや会話の内容を公開しないでください。

## 任意: 作業を並行化または委任する

ワークショップの主要な内容は完了しました。Copilot CLI には、大きなタスク向けに次のコマンドもあります。

- `/fleet` は、独立したサブタスクをサブエージェントに分割し、並行して実行します。
- `/worktree` は、別のタスク用に独立した Git worktree を作成します。
- `/delegate` は、Copilot クラウドエージェントにタスクを送り、非同期で作業させます。プルリクエストが作成される場合があります。

これらのコマンドを使うと、新しい worktree やリモートの作業が作成されることがあるため、必須ではありません。試す場合は、範囲が明確な新しいタスクから始め、通常のワークフローに沿って結果をレビューしてください。非同期エージェントによる作業について詳しく知りたい場合は、[クラウドエージェントのワークショップ][cloud-workshop]に進んでください。

- `/context` と `/compact` を使って、会話コンテキストの管理方法を確認しました。
- `/model` を使って、使用可能なモデルを確認しました。
- `/share` でセッションをエクスポートまたは共有する方法を学びました。
- 並行作業、worktree、クラウドエージェントへの委任に使う任意のコマンドを確認しました。
