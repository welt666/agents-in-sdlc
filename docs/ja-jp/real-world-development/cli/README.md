**[GitHub Copilot CLI][about-copilot-cli]** を使うと、エージェント型コーディングアシスタントとして、ターミナルで GitHub Copilot を利用できます。コードベースを調べ、コードを生成し、コマンドを実行し、外部ツールに接続できます。すべてコマンドラインから行えるため、グラフィカルエディターに切り替えずに作業の流れを保てます。

このワークショップでは、Tailspin Toys の一連のワークフローに取り組みます。

1. GitHub Codespaces でプロジェクトを準備し、Copilot CLI をインストールして、作業環境を確認します。
2. 星評価に対象を絞った変更を加え、ブラウザーでレビューして、最初のプルリクエスト (PR) を手動でマージします。
3. フィルター機能の issue から始め、Plan モードで方針を決め、Autopilot モードで実装し、Interactive モードでレビューします。
4. リポジトリの指示を更新し、フィルター機能の作業に適用します。
5. 既存の `quality-checks` スキルをカスタマイズし、プロジェクトのチェックを実行します。
6. Playwright Model Context Protocol (MCP) サーバーを追加し、ブラウザーでフィルター機能を確認します。
7. QA カスタムエージェントを作成して使い、要件、カバレッジ、検証結果をレビューします。
8. フィルター機能の変更全体をレビューし、その PR に Agent Merge を使用します。
9. コンテキスト、モデル、共有、任意のクラウド委任に使う便利なスラッシュコマンドを確認します。

ワークショップの焦点を絞るため、PR を 2 つ作成します。1 つ目は星評価、2 つ目は指示、スキル、QA プロファイル、テストを更新したフィルター機能です。フィルター機能と品質ワークフローでは、1 つの会話とブランチを共有するため、各ツールを学びながらそれまでの作業を活用できます。

## 前提条件

このワークショップを始める前に、次のものを用意してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランを利用できる GitHub アカウント
- [ ] リポジトリと Codespace を作成する権限
- [ ] ターミナルまたはコマンドライン操作の基本的な知識

> [!TIP]
> 有料プランを利用していない場合でも、学生認証を受けた学生は [GitHub Education][student-plan] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使うエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれています。

> [!NOTE]
> Copilot Business または Copilot Enterprise を使う場合は、管理者が Copilot CLI を有効にしていることを確認してください。
